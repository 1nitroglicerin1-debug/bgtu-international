# БГТУ — Центр международного сотрудничества

Многостраничный статичный сайт для иностранных абитуриентов Брянского государственного технического университета.

## Технологии

- **HTML5** — семантическая разметка
- **Tailwind CSS** (через CDN) — стилизация
- **Font Awesome 6** — иконки
- **GSAP + ScrollTrigger** — анимации появления элементов при скролле
- **Google Fonts** — Inter (текст) + Playfair Display (заголовки)

## Запуск

Просто откройте `index.html` в браузере. Сервер не требуется — все ресурсы подключены через CDN.

## Особенности

- Адаптивный дизайн (mobile-first, брейкпоинты Tailwind)
- Mega-menu навигация на десктопе с выпадающими панелями
- Мобильное меню с аккордеоном
- Анимации появления элементов через GSAP ScrollTrigger
- Карусель отзывов на главной (CSS marquee)
- Timeline-компоненты для пошаговых инструкций
- Форма обратной связи на странице контактов
- Все ссылки между страницами настроены (SPA-подобная навигация)
